# RepTrack

**Тема согласована** ✅

Приложение для отслеживания прогресса в тренажёрном зале. Создано для личного использования и друзей, помогает вести тренировочный дневник, отслеживать результаты и делиться достижениями.

---
## О проекте

**RepTrack** — Android приложение для учета тренировок с возможностью синхронизации данных и обмена прогрессом с друзьями.

### Основные возможности:
- Учёт тренировок и упражнений
- Визуализация прогресса
- Социальные функции (друзья, их статистика)
- Пуш-уведомления о тренировках
- Офлайн-режим с синхронизацией
- Поддержка 2 языков (RU / EN)
- Тёмная тема
